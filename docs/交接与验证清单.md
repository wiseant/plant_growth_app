## 4. 常用验证命令

```bash
# 静态分析 + 单测
flutter analyze
flutter test

# 构建
flutter build apk --debug

# Android 设备/模拟器上检查素材缓存是否落盘
adb shell run-as com.example.plant_growth ls -l cache/plantMediaCache     # 原始 mp4 缓存（flutter_cache_manager）
adb shell run-as com.example.plant_growth ls -l files/plant_frames        # 抽帧结果缓存

# 探测素材时长/编码（远程 URL 或本地文件均可）
ffprobe -v error -show_entries format=duration -show_entries stream=codec_name,width,height -of default=noprint_wrappers=1 <url|file>

# 抽帧相关日志
adb logcat | findstr /i "frame"
```

## 5. 数据 / 素材规范（写 `plants.json` 或新增植物时）

```jsonc
{
  "id": "bean",            // 唯一 id
  "name": "绿豆芽",         // 展示名
  "totalDays": 7,          // 生长总天数（抽帧时间轴分母）
  "videoUrl": "…",         // 必须真实可直连的 mp4；H.264+AAC；建议 ≤10s
  "videoDurationMs": 10000,// 实测毫秒数（用 ffprobe 探测），禁止编造，否则天数→时间戳错位
  "sampleCount": 7,        // 抽帧数量（长周期植物可 < totalDays 降采样）
  "frameWidth": 720        // 帧宽上限（只降不升）
  // "coverUrl": "…",      // 可选；不填则列表页自动抽视频末帧当封面
}
```

- **禁止** `cdn.example.com` 之类占位域名
- 换源后抽帧缓存自动失效（目录名含 URL 摘要）、mp4 缓存按 URL MD5 重下，无需清 App

## 8. 新环境起步（换电脑后照此做）
